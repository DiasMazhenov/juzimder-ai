# Juzimder AI — контекст проекта

Обновлено 21.10.2026. Цель: самостоятельная платформа визуального создания адаптивных сайтов с AI и будущим MCP. Основной репозиторий: https://github.com/DiasMazhenov/juzimder-ai . Репозиторий ведётся в main; ветка отслеживает origin/main. Текущая версия продукта: 00.00.011 (npm SemVer 0.1.11). Постоянный локальный адрес: http://127.0.0.1:8080/ (`npm run serve`, loopback only); повторный запуск безопасно обнаруживает уже работающий Juzimder.

## Принятые решения

- Phase 0: статический аудит PHP-GrapesJS commit 4a464cc3edf54db3ddacdad4b3ddab5bcf7b8589. Подробности в docs/PHP_GRAPESJS_AUDIT.md. Fork отклонён из-за persistence/auth/DB/deployment/licensing проблем.
- Вариант C: собственный PHP 8.2+ API, PDO SQLite, browser JS/CSS, Vite build. PHP hosting без Node runtime. GrapesJS Core 0.23.8, без Studio SDK/форка.
- Каноническая модель: schemaVersion=1, engine=grapesjs, data=getProjectData. Сохраняем pages/frames/components/styles/assets/metadata, не отдельное HTML дерево. Структурная схема в schemas/, authoritative policy в Document validator.
- Project объединяет workspace/site для первого среза. Owner проверяется сервером. Mutations: session + CSRF + validation + expected version.
- Локальные PHP-сессии отдельных SQLite-баз используют разные cookie names; если cookie содержит owner, которого нет в текущей базе, сервер безопасно сбрасывает сессию и просит войти заново.
- Лицензия собственного продукта ожидает выбора владельца. Исходники PHP-GrapesJS не переносились. Notices Core сохранены.

## Реализовано

Auth регистрация/вход/выход, password hashing/session rotation/CSRF/rate limit. Локальная команда `npm run serve` включает dev login `admin/admin` только для loopback соединений; это тестовая учётная запись без отдельной admin-роли и режим запрещён для публичного хостинга. Dashboard: список и создание проектов. Несколько страниц в одном документе. Editor: библиотека структурных секций, слои, traits и style inspector, Flex/Grid, responsive devices, Undo/Redo, текст, изображения по HTTPS URL, preview sandbox, JSON export. На ширине до 800 px панели холста, секций и свойств переключаются отдельными кнопками; есть Cmd/Ctrl+Z, Shift+Z/Y и Cmd/Ctrl+S с защитой полей ввода. Сервер хранит полный document и до 200 транзакционных revisions. Schema v1 уточнена и согласована с runtime policy; malformed/security JSON fixtures проверяются до сохранения. Автосохранение с debounce 1,4 с; CAS 409 при параллельной записи предлагает экспорт или загрузку серверного состояния. История последних 50 ревизий в UI; восстановление пишет старое состояние в новую ревизию и не стирает текущую историю. Выход из редактора сначала пытается сохранить изменения. AI-панель принимает описание только после явного нажатия, показывает проверенный план и палитру, а применение после отдельного подтверждения добавляет встроенные редактируемые секции typed operations одной CAS-ревизией. Описание уходит OpenRouter; Project Data не передаётся. Цвета плана применяются к новым секциям, текущие шрифт и радиус наследуются, а существующие секции и глобальная тема проекта сохраняются.

Инспектор размеров даёт режимы ширины Авто/Hug/Fill и высоты Hug/Fill; четыре min/max поля принимают CSS-размеры с px, %, rem, em, vw или vh. Пустое значение снимает ограничение. Эти стили сохраняются в каноническом Project Data.

Рабочая структура: src/, backend/Domain.php, backend/api.php, backend/migrations/, public/router.php, schemas/, tests/, docs/. Не создавать пустые пакеты для будущих функций. Production сборка public/index.html + assets игнорируется Git и воспроизводится npm ci && npm run build. var/app.sqlite — локальные данные, не Git.

## Ограничения / риски

Не готовый SaaS: нет email verification/recovery, срока бездействия session, production deployment, managed assets/upload, backup restore drill. DB schema v3 применяется при bootstrap; полноценного migration runner для дальнейших схем нет. SQLite для одного сервера, нагрузка не измерена. Core lazy chunk около 1.10 МБ raw / 291 КБ gzip; Vite предупреждает о размере. Свободный пользовательский JS/embed/CSS url запрещены. Панельный мобильный workflow проверен в браузерном viewport 390×844 и 768×1024. Дополнительная частичная responsive matrix: 9/10 секций на mobile 375 px и tablet 768 px, FAQ также на desktop; Image, touch на реальном устройстве, clipboard и полная keyboard/a11y матрица ещё не приняты.

AI UI для design-plan, preview/confirmation и typed preset operations реализованы в 00.00.006; per-project key/model form and encrypted server storage — в 00.00.010. Исправление local stale-session/project-create recovery — в 00.00.011. Не реализованы генерация произвольного AI-контента/компонентных операций, targeted AI edits, live provider acceptance, MCP, Zero Block, advanced Auto Layout, publication/ZIP и custom domains. Реальный OpenRouter provider не проверен. JSON export не static export. Не называть весь MVP завершённым. Полный SBOM/CVE audit upstream не выполнен, audit статический, без exploit proof.
