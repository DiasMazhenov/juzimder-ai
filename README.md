# Juzimder AI

From idea to website. Платформа визуального создания сайтов на базе **GrapesJS Core**. Собственная оболочка редактора, PHP API и переносимое состояние проекта. Самостоятельный продукт, не официальный продукт GrapesJS.

**Версия продукта: 00.00.036 · Статус: foundation.** AI Engine поддерживает несколько редактируемых OpenRouter профилей с зашифрованными ключами и необязательной резервной моделью на временные сбои. AI-дизайн создаёт HTML/CSS-структуру из 3–9 редактируемых секций, показывает sandbox-предпросмотр и импортирует страницу только после подтверждения. Встроенный профиль Taste добавляет предметно-ориентированную идею, серверные структурные gates и обязательную ручную приёмку предпросмотра на desktop/tablet/mobile; рядом остаётся стандартный профиль. Backend ограничивает HTML/CSS allowlist-правилами; JavaScript и внешние ресурсы не принимаются. На OpenRouter передаются текстовое описание и выбранный профиль. Если ответ модели нарушит формат или проверки, выполняется одна исправляющая попытка; повторное нарушение завершает запрос без применения. Модель задаёт визуальные слоты только безопасными пустыми `div.ai-image-slot` маркерами; владелец выбирает изображения из приватной библиотеки проекта в интерфейсе. Байты, имена файлов и ссылки на изображения не отправляются провайдеру. После импорта выбранные файлы становятся обычными редактируемыми изображениями GrapesJS. API-ключ настраивается в «Настройки сайта → AI Engine». В библиотеке доступны PNG/JPEG/GIF/WebP до 4 МБ на файл, общий лимит — 20 МБ и 200 изображений на проект. ZIP экспортирует используемые изображения, публикация включает их в неизменяемый снимок. Также доступны страницы, глобальные стили, SEO и отдельный public origin; production DNS/TLS и custom domains пока не настроены. AI Engine также хранит до 10 Markdown Skills на проект с редактированием и активацией. Выбранный Skill и его чек-лист отправляются в OpenRouter только при генерации; перед импортом пользователь отмечает ручные проверки. Блок juzimder-rules добавляет серверные проверки заголовков, секций, текста и адаптивного CSS с одной исправляющей попыткой и отказом при повторном нарушении. Кнопка «Разобрать Skill с AI» предлагает правила и ручные проверки с цитатами из исходника; владелец проверяет полноту перед переносом черновика в форму. Остальные требования проверяются вручную; идеальное следование произвольным инструкциям не гарантируется. npm SemVer — 0.1.37, productVersion — 00.00.037; версия отображается в dashboard и editor.

Реализовано: локальная регистрация/вход, проекты с проверкой владельца, несколько страниц, десять структурных секций, глобальная тема проекта (восемь цветов, типографика и скругление) с сохранением в валидируемых настройках проекта и синхронизацией с Project Data, слои и инспектор стилей/свойств, Flex/Grid, desktop/tablet/mobile canvas, Undo/Redo, sandbox preview, debounce-автосохранение, история до 200 ревизий с безопасным восстановлением, защита от конфликта версий, JSON export и статический ZIP export.

AI foundation: серверный OpenRouter adapter, constrained design-plan endpoint и полноценная генерация HTML/CSS с предпросмотром и отдельным подтверждением импорта. Отдельный authenticated `POST /api/projects/{id}/operations` принимает ограниченный список typed operations (`create`, `update_content`, `update_styles`, `update_layout`, `delete`, `move`, `reorder`) и сохраняет каждое успешное применение новой CAS-ревизией. Удаление требует `confirm: true`; создание назначает стабильные component IDs. API-ключ, основная и резервная модели OpenRouter настраиваются в «Настройки сайта → AI Engine» конкретного проекта; ключ хранится сервером в зашифрованном виде и не входит в Project Data. Полный live-тест генерации, применения, сохранения/reload и публикации остаётся отдельным acceptance gate; синтетические и fixture-проверки не тарифицируют провайдера. Также не реализованы targeted AI edits, MCP, Zero Canvas, custom domains и templates marketplace.

## Локальный запуск

PHP 8.2+ (PDO SQLite, DOM/libxml, mbstring, Zip), Node 22.12+ для сборки. Проверено на PHP 8.5.8 и Node 24.15.0.

```sh
npm ci
npm run build
npm run serve
```

После `npm run serve` приложение открывается по уникальному локальному адресу [http://juzimder-ai.localhost:8080](http://juzimder-ai.localhost:8080). Команда проверяет этот адрес: если Juzimder уже работает, повторный запуск сообщит URL и завершится без ошибки занятого порта; старые адреса `127.0.0.1:8080` и `localhost:8080` перенаправляются на него. Для локальной разработки команда включает loopback-only вход `admin/admin`; при первом входе создаётся отдельный тестовый аккаунт. Сервер остаётся привязан только к этому компьютеру; не включать dev login на публичном сервере. Локальные сессии изолируются по пути SQLite-базы, а после переключения базы устаревшая сессия сбрасывается с предложением войти снова. Данные — `var/app.sqlite` вне web root. API-ключ AI вводится только в «Настройки сайта → AI Engine» и не задаётся через переменные окружения. Локальный опубликованный сайт использует host вида `<project-id>.juzimder-ai.localhost:8080`; production требует wildcard DNS/TLS и конфигурации `JUZIMDER_PUBLIC_HOST_SUFFIX`. `JUZIMDER_DB` можно использовать для отдельной локальной базы; `.env.example` документирует только серверный путь к базе, dotenv не подключён. Для hot reload: параллельно `npm run dev`.

```sh
npm test
```

Стек: GrapesJS 0.23.8, Vite 8.3.4, browser JS/CSS, native PHP/PDO SQLite. Node не требуется на PHP hosting после сборки. Backend и SQLite расположены вне public. Текущая версия предназначена для локальной работы; перед публичным размещением пройти [security checklist](docs/SECURITY.md) и [deployment guide](docs/DEPLOYMENT.md).

## Проверка разбора Skills · 00.00.037

Реальная модель выявила избыточное дублирование id/label внутри ruleJson. Теперь модель возвращает идентификатор и название один раз; сервер собирает канонический контракт и проверяет его прежним валидатором. При неверных цитатах или формате допускается одна исправляющая попытка с безопасным кодом причины, без передачи отвергнутого ответа. Использование токенов суммируется, неизвестные значения остаются неизвестными; UI предупреждает о дополнительном расходе. Ошибки провайдера отличаются от ошибок разбора, сырые ответы и секреты не раскрываются.

Live PASS: синтетический pottery Skill разобран через существующую бесплатную модель nvidia/nemotron-3.5-super-vl:free; 5 автоматических правил и 2 ручных требования сверены с исходником. QA Skill сохранён в проекте Design token QA (библиотека v1) и повторно открыт после reload: исходник, правила и три объединённых ручных пункта сохранились. Активный AI-профиль и выбор Skill по умолчанию не менялись. Генерация страницы с этим сохранённым Skill, визуальная desktop/mobile приёмка и применение результата — NOT RUN, следующий этап. Это не подтверждает безошибочное следование произвольному Skill.

Проверки: npm test, npm run build, PHP syntax и git diff --check — PASS. Известное предупреждение Vite: GrapesJS chunk больше 500 КБ.
