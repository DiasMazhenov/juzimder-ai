# Tabler Outline subset

Source: https://github.com/tabler/tabler-icons/tree/main/icons/outline
Retrieved 2026-10-23. Eight original SVG files are kept alongside the MIT LICENSE.
The generated catalogue contains these exact shapes with a fixed slate stroke (#64748b), plus an embedded MIT notice in each image. All icons use a 24x24 viewBox and a 2-unit outline with round caps/joins; rendered size defaults to 32px. No CDN or runtime fetch is required.

Semantic IDs: spark, check, clock, heart, target, arrow, list, diamond.
Only exact catalogue data URIs are accepted by the server and JSON schema; arbitrary SVG and arbitrary data URLs remain forbidden. Updating this catalogue requires updating the schema enum and running the export/security tests.
