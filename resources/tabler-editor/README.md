# Tabler Outline editor icons

Official source: https://github.com/tabler/tabler-icons/tree/main/icons/outline
Retrieved 2026-10-24. MIT license retained in LICENSE and embedded in every inline catalogue SVG. The editor uses local files only, no CDN. Original assets are unmodified apart from catalogue accessibility/class attributes and embedded notice.

Core icons use the supported GrapesJS icons configuration. App controls, Flex controls and Rich Text actions use this same outline catalogue. Additional `player-play`, `message`, `list` and `vector-bezier` source SVGs are bundled locally for the Zero Block element palette. `stethoscope`, `microscope`, `baby-bottle` and `first-aid-kit` are included as safe Zero AI Vector choices. SVG entries retain the Tabler MIT notice. Dynamic frame/tool UI is observed only in the host document; generated page iframe content is never rewritten.
